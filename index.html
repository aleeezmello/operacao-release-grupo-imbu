Git e GitHub

O que é Git?

Git é um sistema de controle de versão utilizado para acompanhar as alterações realizadas em um projeto.

O que é GitHub?

GitHub é uma plataforma que permite armazenar projetos e colaborar com outras pessoas.

Principais comandos Git

  • git clone - clona um repositório.
  • git status - verifica o estado dos arquivos.
  • git add - adiciona alterações.
  • git commit - registra alterações.
  • git push - envia alterações para o GitHub.
  • git pull - atualiza o projeto.

Branches

Branches são ramificações do projeto que permitem desenvolver funcionalidades separadamente.
